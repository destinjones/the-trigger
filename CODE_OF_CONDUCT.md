# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, argue with the data and the method rather than with people, and assume good faith.

The subject here is political. Disagreement about whether a dividend should happen, or about how the index weighs things, is welcome and is what the weights files are for. Personal attacks, harassment, and posting other people's private information are not.

## Reporting

Report conduct problems privately to the maintainer through GitHub's private vulnerability reporting (Security tab, "Report a vulnerability"), marking the report as a conduct issue, or by contacting the repository owner directly. Reports are kept confidential.

Maintainers may remove comments, issues or contributions that break these rules, and may block repeat offenders.
